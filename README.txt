اشتہار بناؤ — اپ گریڈ شدہ سورس کوڈ

اس ورژن میں:
- 12 کاروباری اقسام
- 300 قابلِ ترمیم ڈیزائن variations (12 × 25)
- اردو، پشتو، انگریزی انٹرفیس
- ٹیمپلیٹ تلاش اور کیٹیگری فلٹر
- کاروبار، آفر، قیمت، پرانی قیمت، فون نمبر
- تصویر شامل کرنا اور PNG اشتہار شیئر کرنا

چلانے کا طریقہ:
1. Node.js LTS انسٹال کریں: https://nodejs.org/en/download
2. اس فولڈر میں Terminal کھولیں۔
3. چلائیں:
   npm install
   npx expo install --fix
   npx expo start
4. موبائل میں Expo Go سے QR اسکین کریں۔

APK:
   npm install -g eas-cli
   eas login
   eas build -p android --profile preview

نوٹ: 300 ڈیزائن مختلف قابلِ ترمیم رنگوں، ہیڈنگز اور لے آؤٹس پر مبنی ہیں؛ یہ 300 علیحدہ AI تصاویر نہیں ہیں۔ AI ٹیکسٹ/تصویر اور ویڈیو فیچرز اگلے مرحلے میں API اور اضافی کام کے ذریعے شامل ہوں گے۔
